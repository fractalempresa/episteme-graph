# Contribuir a EpistemGraph

Gracias por tu interés. EpistemGraph es infraestructura epistemológica abierta — cada contribución fortalece la confianza en el conocimiento académico global.

## Cómo empezar

1. Fork del repositorio
2. Crea una rama: `git checkout -b feature/nombre-descriptivo`
3. Commits con mensajes claros en español o inglés
4. Pull Request con descripción del cambio y su impacto en el grafo

## Áreas prioritarias

- **Motor NLP**: mejoras en detección de inconsistencias lógicas
- **Renderizado 3D**: optimización del grafo con Three.js
- **Criptografía**: módulo de trazabilidad de autoría
- **Conectores**: integración con CrossRef, Semantic Scholar, arXiv
- **Documentación**: tutoriales, casos de uso, traducción

## Issues

Etiquetas activas:
- `good first issue` — entrada para nuevos contribuidores
- `core-engine` — motor NLP y lógica de auditoría
- `graph-rendering` — visualización 3D/4D
- `crypto-trace` — trazabilidad criptográfica
- `research` — investigación epistemológica y diseño conceptual

## Código de conducta

Este proyecto existe para mejorar la calidad del conocimiento humano. Las contribuciones deben ser honestas, verificables y respetuosas — los mismos principios que el sistema promueve.
